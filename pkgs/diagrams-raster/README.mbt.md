# Portable raster export

`moonrockz/diagrams-raster` converts SVG generated by diagrams.mbt to PNG and
JPEG bytes on wasm, wasm-gc, JavaScript and native. It also exports a bounded
source-bound playback plan as a real animated GIF. The module needs no browser,
external executable, remote service, UI framework or host font discovery.

The existing text renderers keep their signatures. Binary results use
`RasterResult.image`, with immutable bytes, media type, actual dimensions and
format. Failure returns diagnostics and no partial image.

```mbt check
///|
test "PNG is the default still format" {
  let svg = "<svg width=\"32\" height=\"16\"><rect x=\"4\" y=\"4\" width=\"8\" height=\"8\" fill=\"red\"/></svg>"
  let result = @raster.rasterize(
    svg,
    options=@raster.StillOptions::new(size=Width(128)),
  )
  assert_eq(result.diagnostics.length(), 0)
  let image = result.image.unwrap()
  assert_eq(image.media_type, "image/png")
  assert_eq(image.width, 128)
  assert_eq(image.height, 64)
}
```

```mbt check
///|
test "JPEG requires an explicit opaque background" {
  let svg = "<svg width=\"32\" height=\"16\"><rect width=\"8\" height=\"8\" fill=\"red\"/></svg>"
  let result = @raster.rasterize(
    svg,
    options=@raster.StillOptions::new(
      format=Jpeg(quality=85),
      background=@raster.Rgba::white(),
      theme=Light,
    ),
  )
  assert_eq(result.diagnostics.length(), 0)
  assert_eq(result.image.unwrap().media_type, "image/jpeg")
}
```

## Size, background and theme

`RasterSize` accepts original dimensions, a positive finite scale, a width, a
height or a fitting box. Width and height preserve the SVG viewBox aspect ratio.
`Fit(w,h)` fits the complete diagram inside the box. Output dimensions round up.
No option crops the diagram.

PNG defaults to a transparent background. JPEG accepts quality 1–100 and requires
an opaque background. Explicit export backgrounds replace only the emitter's
top-level `<rect class="bg">`. Nested icon, mask and foreground backgrounds stay
intact. Compositing affects a derived export scene and never rewrites the input.
Adaptive SVG resolves to the explicit light or dark export theme. Fixed diagram
colors retain their supplied values.

## Explicit fonts

`FontSet::default()` is a licensed profile using Noto Sans Mono regular/bold and
Noto Sans Symbols 2. It explicitly maps the writer's documented monospaced CSS
stack to those faces. It does not inspect system fonts or fetch fonts. Exact
originals, licenses, derivation ranges and byte hashes are under `fonts/`.

The default subset covers Latin, Greek, Cyrillic, punctuation, arrows, control
pictures, box drawing and required checkbox symbols that exist in those source
fonts. Every scalar in the current gallery labels has a checked regression.
A required glyph outside that set produces `raster/missing-glyph`. Supply an
explicit static TrueType glyf face through `FontFace::new` and `FontSet::new`
to cover other supported labels or family/style choices. Font family, weight
and italic policy are explicit per face. The renderer diagnoses a missing style.

The static outline profile validates font directories, table bounds, cmap
ranges, simple glyph buffers and compound glyph cycles before calling the font
parser. It supports horizontal kern format 0. Variable, CFF, color, compound
point-attached or sheared glyph profiles and scripts that require complex
shaping return diagnostics. They are never replaced with blank glyphs or bitmap
fallback text.

`FontSet::subset_for_svg` returns a checked font set containing only the SVG's
label codepoints. Subsetting retains all required compound glyph dependencies
and preserves the rendered pixels. Build tools can embed those immutable bytes
in an offline artifact instead of embedding the full default profile in every
player. This method returns `FontSubsetResult` with the same no-partial-result
rule. It neither mutates supplied fonts nor changes the source.

## Bounded work and reproducibility

`RasterLimits::default()` bounds source units, XML nodes, dimensions, pixels,
label glyphs, encoded bytes, frames and cumulative animation pixels. The default
limits are 16 Mi UTF-16 source units, 200,000 XML nodes/attributes, 16,384 pixels
per dimension, 16 Mi pixels per image, 100,000 label glyphs, 32 Mi encoded bytes,
300 frames and 64 Mi cumulative animation pixels. XML nesting is capped at 256.
Unique supplied font bytes share the source budget. A font has at most 16 levels
of compound glyphs and 100,000 expanded points per glyph.

Invalid options fail before unsafe allocation. Source, font, normalized SVG,
pixel and output exhaustion produce identified diagnostics. Missing resources,
malformed XML, unsupported generated content and required glyph absence do not
produce a successful image. The generated-SVG profile includes every implemented
family, explicit palette resolution, text outlines, icons, curves, markers,
transforms, clipping and connector crossing masks. Arbitrary third-party SVG is
outside this API's contract.

Equal inputs, options and fonts produce equal encoded bytes on all four targets.
PNG uses the qualified published codec. JPEG uses a licensed fixed-point
adaptation whose pinned integer DCT basis avoids platform cosine differences.
Its accumulations fit exactly below 2^40, including the Double integer
representation used to avoid JavaScript BigInt cost. File and network I/O belong
in caller adapters.

See `tests/raster-spike/` for backend selection evidence and
`tests/raster-acceptance/` for public binary fixtures decoded independently in
Chromium. Run `mise run test:raster-consumer` for a fresh public consumer.

## Dependency and font licenses

The SVG/XML/CSS, font and PNG dependencies use Apache-2.0. The GIF dependency
uses MIT. The JPEG adaptation retains its upstream attribution in `NOTICE.md`.
The bundled Noto fonts and deterministic subsets use SIL OFL-1.1. See
`fonts/OFL.txt`, `fonts/source.json` and `fonts/default/profile.json`.

## Animated GIF

`export_gif(scene, plan)` requires a validated plan bound to that scene's source.
It samples logical time, including repeated and concurrent occurrences, reversed
final curves, node visits and connector masks. Export does not run a clock or
change the scene or plan. `GifSampler` exposes the same pure samples for callers
that inspect frames.

```mbt check
///|
test "export a bounded source-bound animation" {
  let view = @swimlane.Swimlane::new("review", [
    @swimlane.Node::new("A"), @swimlane.Node::new("B"),
  ], [@swimlane.Connection::new("AB", "A", "B")])
  let scene = @svg.SvgRenderer::new().scene(@render.Diagram::Swimlane(view)).scene.unwrap()
  let key = scene.catalog.connection("AB").unwrap().key
  let plan = @animation.PlaybackPlan::scenario(scene.catalog,
    @animation.Motion::serial([Step(key, 100L), Step(key, 100L)]),
  ).plan.unwrap()
  let result = @raster.export_gif(scene, plan,
    options=@raster.GifOptions::new(size=Width(64), frame_rate=10, loop_behavior=Once),
  )
  assert_eq(result.image.unwrap().media_type, "image/gif")
}
```

`GifInterval::Full` covers the finite plan's duration or one illustrative period.
Use `Interval(start_ms=..., end_ms=...)` to choose an explicit bounded interval.
The exact first and final logical samples are included. Every sample has a
positive hold, including the final sample; the encoded duration therefore
includes that final-frame hold beyond the sampled interval. Delays round to
centiseconds with a 10 ms minimum. Frame rate is an integer from 1 to 100.

`GifLoop::Once` omits the loop extension. `Forever` repeats indefinitely when
viewed, while the exported file still has a finite frame count. `Repeat(n)` means
n additional plays, for n from 1 to 65,535. GIF uses a deterministic 256-color
3:3:2 palette. It is opaque and requires a background color. Colors can differ
from PNG/JPEG after quantization. No transparent or partial frame is returned.

Dimension, frame, cumulative-pixel and output limits apply before unsafe work.
An interval that exceeds a finite plan, an empty plan or an exhausted budget
fails with diagnostics. Shorten the interval, choose smaller dimensions or lower
the frame rate explicitly instead of truncating the requested animation.

`gif_export_data` prepares versioned source-bound scene/plan data for an offline
worker. `Rasterizer::new(fonts)` is an immutable explicit-font profile whose
`rasterize` and `export_gif_data` methods use the same conversion and codec path.
The worker protocol validates source fingerprints, visible bindings, schedules
and aggregate budgets. Its fingerprint checks consistency, not authenticity.
`FontSet::export_data` deduplicates shared face bytes, and `from_export_data`
validates the received profile. The browser adapter supplies per-player subsets
or the gallery's complete declared default profile. Published libraries depend
on no browser UI framework.
