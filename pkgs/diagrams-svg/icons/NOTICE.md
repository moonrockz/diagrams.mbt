# Bundled diagram symbols

The participant coverage source is ZenUML core 3.47.9, npm gitHead
`e3f93e0eb65d23fa3520e8691a5bca883853aa4b`, specifically
`src/components/DiagramFrame/Tutorial/LazyIcons.ts` and its `CloudIcons.ts` barrel.
The registry has 523 keys, which map to 503 distinct normalized vector assets.
It is larger than the upstream static SVG icon map. Keys use the upstream
case-insensitive lookup. Aliases share art only where that registry does.

`catalog.json` records every key, source path, original SHA256, normalized SHA256,
asset identity, family, attribution and provider terms. `assets/<sha256>.svg`
preserves the exact source bytes. `catalog.generated.mbt` compiles normalized
paths, groups, paints and local definitions into typed writer nodes. It contains
no runtime SVG parser. CSS classes become presentation attributes. Gradients,
masks and clipping references receive per-output IDs. Geometry and provider
colours remain intact. The five architecture defaults are original simple
vector drawings in `icons.mbt`.

The upstream repository's MIT notice is reproduced in `LICENSE-ZENUML`.

Only referenced definitions enter an SVG. A white backing plate preserves dark
and light visibility without changing provider colours. Icon identity remains
accessible separately from the participant or service name. Unknown names keep
labels and render a marked fallback with a diagnostic.

`mise run icons:generate` writes both the typed vector catalog and a separate
core identity-only registry. `mise run validate:icons` verifies source digests and
reproduces those generated files. The complete contact sheet is generated by
four-target tests and linked from `mise run gallery`.

The `externalsystem` icon has its own explicit licence notice: **16pxls (c) by
Paul mackenzie <paul@whatspauldoing.com>**, Creative Commons
Attribution-ShareAlike 4.0 International. Its full licence text is reproduced in
`LICENSE-CC-BY-SA-4.0`; this specific licence supersedes the generic repository
notice for that asset. The normalized art retains that licence. Geometry is
preserved; normalization expands CSS classes and scopes local IDs. Each used
participant symbol carries its author/provider, terms, source and normalization
notice in its exported SVG definition, including static downloads.

## Size qualification

The frozen catalog has 523 keys, 503 normalized assets and 504 byte-distinct raw
SVGs. Raw source assets total 1,579,240 bytes; `catalog.json` is 2,328,026 bytes,
and the generated typed vector source with export notices is 2,460,667 bytes.
The seven-symbol light interaction in the review gallery is 42,265 UTF-8 bytes;
the nine-service aligned grid is 17,164 bytes. Outputs include only used symbols,
with aliases and repeated uses sharing definitions. The catalog does not enter
the player's JavaScript. These are source/artifact sizes, not compressed package
or native executable sizes.
