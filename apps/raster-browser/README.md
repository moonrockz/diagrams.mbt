# Raster browser adapter

This unpublished build tool compiles the portable raster library into an offline
Web Worker. The font asset builder prepares explicit deduplicated font resources.
The published diagram libraries contain no browser UI dependency.

`assets/THIRD-PARTY-NOTICES.txt` retains upstream license and attribution text
for the converter and default fonts. Both generated adapter variants carry the
complete notices in an offline-readable JavaScript comment. Generation changes
only comment line endings to LF, matching HTML parsing and repository assets.
