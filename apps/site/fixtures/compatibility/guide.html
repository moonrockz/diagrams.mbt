BPMN and flow animation

Use moonrockz/bpmn independently to read, write, validate and traverse BPMN XML. It depends on MoonBit core only. It retains processes, collaborations, choreography, conversations, diagram interchange and vendor extensions. Reference resolution accepts explicit resources; namespace URIs and import locations never cause network or filesystem access.

The BPMN document guide has compiled examples for reading, typed construction, writing, validation, reference indexes and bounded graph traversal. Syntax, structural and reference diagnostics remain distinct. Source reproduction keeps the original spelling; canonical writing is deterministic.

Select and render a view

Use diagrams-bpmn to select a process, collaboration or diagram plane. Automatic selection requires one view at its selected tier. Select explicitly when a document has multiple candidate views. Choreography and conversation documents remain typed, but their rendering is deferred and produces an explicit diagnostic.

The SVG guide documents supplied-DI, preferred-DI and automatic geometry policies. Supplied views preserve exact coordinates, label bounds and waypoints. Automatic layout deliberately ignores DI. Limits fail with diagnostics; legibility findings describe supplied geometry without silently moving it.

Compare the process in dark and light, or its automatic dark and light layout. Read the process XML.

The collaboration has an expanded subprocess and a black-box participant. Compare its supplied dark and light views, or the collaboration XML.

Follow connections offline

diagrams-animated generates one HTML artifact with inline SVG, data, styles and runtime. It starts still and needs no network, external font or UI framework. Its controls support keyboard operation, reduced motion, hidden-page suspension and static printing. Download SVG returns the exact canonical static bytes and preserves viewer state.

Open the collaboration player in dark or light, the automatic process player, or the finite concurrent BPMN scenario.

The finite sequence scenario selects one alternative, repeats a loop twice, and runs parallel branches. Open it in dark or light. Unselected messages remain visible. Repeated participants do not create invented interaction cycles.

The pure motion guide documents occurrences, finite serial/parallel plans, explicit branch choices, deterministic sampling and bounded structural queries. Illustrative flow repeats authored connections. A structural route is a path over drawn connections. Conditions, events and gateway synchronization are not evaluated. Neither mode executes a business process or simulates tokens.

Review and verify

Run mise run gallery and open _gallery/index.html for the complete review set, including XML for choreography and conversation documents. After snapshot qualification, mise run gallery -- --existing-output --check --qualify checks all stored files, links and browser output without a workspace/site rebuild. Run mise run test:animation for the full offline player qualification.

mise run gallery -- --site-assets refreshes the selected site examples from verified snapshots. Versions and publication remain separate owner decisions.
