moonrockz/diagrams

Diagramming for MoonBit. The library will support formats such as Mermaid, PlantUML, Draw.io and Graphviz DOT.

Types

Diagnostic

pub(all) struct Diagnostic {
  code : String
  severity : Severity
  message : String
  span : Span?
} derive(Eq, @moonbitlang/core/debug.Debug)

A problem that a reader, a converter or a renderer found. code is stable, for example mermaid/unknown-statement. span is absent when the problem has no place in a source text.

Position

pub(all) struct Position {
  offset : Int
  line : Int
  column : Int
} derive(Eq, @moonbitlang/core/debug.Debug)

A place in a source text. offset counts UTF-16 code units from the start. line and column start at 1, and column also counts UTF-16 code units.
