Read diagram source. Build typed models. Render SVG and offline players.

A MoonBit library for Mermaid sequence, swimlane, ZenUML and architecture diagrams, BPMN documents, and native PlantUML regex, EBNF, JSON and YAML blocks.

Portable models and output

The libraries build for wasm, wasm-gc, JavaScript and native targets. SVG output needs no scripts. Offline players add playback and bounded structural exploration without a server.

Diagram illustration does not execute a process or simulate BPMN tokens. Regex and EBNF traces describe evidence supplied by an external engine. Choreography and conversation documents are retained and validated; their rendering is deferred.

General PlantUML diagrams, Draw.io and Graphviz DOT are planned. The design overview explains the document, model and rendering boundaries.
